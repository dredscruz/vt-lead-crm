⬆ Import Leads

In Google Sheets click Share → Anyone with the link → Viewer, then paste the link here. The sheet must have a header row — columns like Name, Company, Email, Phone, Role, Source, Stage, Value ($/mo), Notes are matched automatically.

🟢 Push Leads to a Google Sheet

This writes your leads into the sheet you pick — use any sheet other than your import source. One-time setup per sheet:

1. Open the sheet → Extensions → Apps Script, delete anything there, and paste the script shown below.
2. Click Deploy → New deployment → Web app. Set "Who has access" to Anyone, then Deploy and copy the Web app URL (ends in /exec).
3. Paste that Web app URL here.
